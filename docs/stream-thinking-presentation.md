# 流水思考呈现

Rikka 风格按 25ms 脉冲揭示一个 Unicode 码点，不改写会话原始全文；完成事件立即冲刷尾部并自动折叠。点击标题可恢复全文，手动折叠/展开同时更新全局默认偏好。设置 → 工作台 → Coding → 默认收起思考过程提供显式入口。

只有同轮后续正文已经出现，“直接看回答”才可用：收起当前面板并滚到该正文，不取消模型、不伪造回答。折叠态明确显示“首句预览”，不是新增模型请求生成的语义摘要。完整输出档保持原有整段揭示行为。

既有秒表/AnimatedVisibility 保留。当前 UI 计时不代表服务端计算耗时；设备旋转/后台、低端机动画和触摸需真机验收。
