# 静态分析 job 的 Maven 依赖清单（单一事实源）
#
# 用途：.github/workflows/ci.yml 的 static-analysis job 用它做两件事——
#   1) 生成 actions/cache 的 key（hashFiles 本文件）：清单变化 → key 变化 →
#      缓存自动失效，不会出现「加了 jar 但忘了 bump 静态版本号」导致每次都
#      重新下载的问题（#353-⑤）；
#   2) 驱动下载循环：本文件每一行是一个 Maven 坐标路径，脚本直接 curl 它。
#
# 格式：每行 `<group/path>/<artifact>/<version>/<artifact>-<version>.jar`
#       `#` 开头为注释，空行忽略。
