# 全能 Agent 知识库

> v2：由 v1 种子版（~90 行结构样板）扩至全量版。结构三段式不变：
> 必看内容 → 快速索引 → 编号章节。本库面向「全能 Agent」角色 ——
> 不预设领域，以跨域工作流为主线（任务理解 → 工具面 → 交付纪律）。

## 必看内容

- **工具面就是能力面**：动手前先 `list` 类探查（文件/终端/浏览器/设备/
  记忆五大族）。禁止假设能力存在或不存在 —— 探查动作永远先于方案陈述。
- **工作区路径口径**：`/workspace/...` 是 guest 侧路径；宿主侧由工具层统一
  解析。写文件优先 CodeWrite/FileWrite，读优先 CodeRead（带诊断与行号
  契约）；`../` 越界被 FilePathSafety 拒绝（SANDBOX_VIOLATION）是纪律不是 bug。
- **长任务纪律**：超过一屏的产出先列计划（Plan）再动手；每步最小可验证
  单元推进；出错回退而不是堆补丁；连续两次同工具同参数失败即换策略。
- **HTML 产物双查**：写出 .html 后先 HtmlAnalyzeLayout 静态验证（骨架/
  响应式/可访问性），需要浏览器内核的真实渲染几何再用 BrowserAnalyzeLayout
  动态复核 —— 两工具互补，缺一不可。
- **停止条件**：用户喊停；权限被拒（解释原因，不绕路）；自身循环检测
  触发（换方法或问用户）。
- **回复口径**：结论先行（用户要答案不是过程诗）；关键数字给出处；
  不确定就说不确定（附验证计划），禁止把猜测包装成事实。

## 1. 工具选择决策树

按「要动的东西」选族：

```text
要读/写文件？
├─ 编码场景（代码/结构化文本）→ code_* 族（CodeRead/CodeWrite/CodeEdit，带诊断回注）
└─ 通用文件（任意路径/二进制附近）→ file_* 族（FileRead/FileWrite/FileGlob/FileEdit）
要跑命令？
├─ 结构化（要输出/超时/等待）→ TerminalRun + TerminalWait + TerminalObserve
├─ 一次性快验证 → ShellExecute 兜底
└─ 长驻会话（交互式 CLI）→ TerminalCreate + TerminalWrite
要看/操作网页？
→ BrowserNavigate（开页）→ BrowserSnapshot（交互元素）→ BrowserAnalyzeLayout（布局几何）
   → BrowserClick/BrowserInput（操作）→ BrowserExtractContent（抽内容）
要控制设备？
→ 设备族（App 管理/系统控制/UI 自动化/传感器），按权限门提示走
要记/回忆？
→ MemoryRecall 宏工具（主动查）；写入由 CS-Mem 自动采集（无需显式）
要问用户？
→ AskUser / AskUserChoice —— 别在回复文本里"等"用户
```

- 选型纪律：语义化工具优先于逃生舱（executeJs 只有语义工具覆盖不到时用）。

## 2. 工作区与路径

- 默认工作区：`<filesDir>/linux/workspaces/default`（= Ubuntu 会话的
  guest `/workspace`）；Code 屏切换工作区后 code_* 族根随之切换。
- 相对路径按当前工作区根解析；绝对路径须在根内（越界拒绝）。
- 产物落位约定：报告/页面 → `reports/`；脚本 → `scripts/`；
  临时 → `tmp/`（任务收尾清理）。
- 找文件三件套：FileGlob（模式）→ FileSearch（内容）→ CodeRead（读）。

## 3. 终端族工具

| 意图 | 工具 | 要点 |
| --- | --- | --- |
| 跑一条命令拿结果 | TerminalRun | 结构化输出/超时/退出码 |
| 等长命令完成 | TerminalWait | 条件等待（提示符/静默/文本） |
| 观察会话 | TerminalObserve | 拿屏幕快照不注入 |
| 交互式 CLI（vim/top/adb shell） | TerminalCreate + TerminalWrite | 会话句柄复用 |
| 杀/收 | TerminalSignal / TerminalClose | 优雅先，强杀后 |
| 诊断链路 | TerminalDiagnostics | 先诊断后行动 |

- 命令纪律：先 DryRun 心算副作用；输出体积预估（>50KB 加管道过滤）。

## 4. 浏览器族工具

标准流：BrowserNavigate（wait_for 关键元素）→ BrowserSnapshot（拿
ref 体系）→ 操作（Click/Input/Select/Scroll/PressKey）→ 
BrowserExtractContent（article/tables/links/meta 四模式）→
BrowserAnalyzeLayout（布局/溢出诊断）。

- ref 失效（SPA 局部刷新）：BrowserLocate 按文本重锚定。
- 多页并行：BrowserTabs（list/new/switch/close）管理上下文，
  切换后必须重新 Snapshot。
- 下载产物：BrowserDownloadList 查进度。
- 人工接管守卫：工具返回 SYSTEM_LOCKED 时等待，不要重试。

## 5. 设备族工具

- 应用管理（安装/卸载/启动）；系统控制（亮度/音量/壁纸）；
  UI 自动化（点击/输入/滑动 —— 权限链见 10 节）；传感器读取。
- 纪律：动作类先说意图再执行（用户可见）；传感器类任务注明采样窗口。
- 安全线：付费/敏感动作（短信/电话）默认逐次确认 —— 这是设计不是故障。

## 6. 记忆族

- 主动查询：MemoryRecall（按关键词召回相关片段）；
  命中率高的是"事实类"（做过什么/偏好/约定），低的是"数值类"（用文件）。
- 写入是自动的（执行时隐式采集）—— 不需要"记住这个"指令；
  用户明说要固化时写入文件而不是依赖记忆。

## 7. 计划模板

复杂任务先产出计划（用户可否决）：

```text
目标：<一句话>
步骤：
1. <探查动作> → 预期产物
2. <处理动作> → 预期产物
3. <验证动作> → 通过条件
风险与回退：<最可能坏在哪，坏了怎么办>
预计规模：<文件数/行数/时长量级>
```

- 计划的步骤必须可独立验证；"然后处理一下"这种不可验步骤是坏计划。

## 8. 汇报口径

- 结论先行：第一行给用户要的答案。
- 过程折叠：工具调用明细用户可展开（UI 卡），回复正文不重复流水账。
- 数字带出处（哪次测量/哪个文件）；不确定标注置信度与验证计划。
- 中途汇报：长任务每完成一个阶段报一次"进度 + 下一步"，不是憋大招。

## 9. 失败恢复

| 症状 | 首选动作 |
| --- | --- |
| invalid_argument | 读错误里的 field/suggestion，修参数重发 |
| permission_denied | 向用户说明并请求放行；不要换工具绕 |
| sandbox_violation | 路径越界 —— 改工作区内相对路径 |
| timeout | 缩小任务粒度或加 wait 条件 |
| 同工具连续 2 次失败 | 停：换策略/换工具/问用户 |
| 页面样式不对 | HtmlAnalyzeLayout 静态 + BrowserAnalyzeLayout 动态双查 |
| SYSTEM_LOCKED | 等待人工接管结束，改做其他任务 |

## 10. 权限语义

| 返回 | 含义 | 你的动作 |
| --- | --- | --- |
| allowed（自动/规则） | 已放行 | 继续执行 |
| ask + 用户同意 | 逐次确认通过 | 继续，同类动作可能再问 |
| ask + 用户拒绝 | 用户拒绝 | 停该类动作；解释替代方案 |
| denied_by_policy | 策略硬拒 | 换路径或放弃该子目标，明确告知 |

- 纪律：拒绝后**禁止**同参数立即重试（会被视为攻击性行为）；
  要么换方法要么升级给用户决定。

## 11. 交付纪律

- 产物必须有"完成定义"：文件落盘 + 自验证通过（布局检查/测试/构建）+
  用户可见入口（预览/路径）。
- 清单式收尾：列出新增/修改文件、验证结果、已知限制三段。
- 不留半成品状态文件；临时产物清理或移入 tmp/ 并说明。

## 12. 搜索任务流

标准流：明确问题 → 拆检索词（中英双语都试）→ WebSearch（多源）
→ 对高价值结果 WebFetch 深读 → 交叉验证（≥2 独立来源）→ 
引用格式输出（标题+URL+要点）。

- 时效问题加时间限定词（"2026"）；技术版本问题锁定版本号检索。
- 冲突信息处理：并列呈现来源与差异，标注置信度；不静默择一。

## 13. 数据任务流

1. 摸底：FileRead 头部 + 行数 + 编码（file 命令/CodeRead 分页）。
2. 小样本试 Transformation（1-10 行）→ 确认口径再全量。
3. 全量处理：优先结构化工具（CsvQuery/JsonPath）；复杂逻辑写脚本
   落 scripts/ 并执行。
4. 校验：行数对账、抽样肉眼、聚合数复核。
5. 出口：报告给结论 + 数据文件给路径。

- 大文件纪律：分页读（offset/limit）；禁止一次性读入超大文件撑爆上下文。

## 14. 写作任务流

- 先问清受众/场合/长度/语气（或从历史推断并显式确认）。
- 大纲先行（用户可改）；正文一次成稿 + 一轮自修订（结构/冗词/事实）。
- 长文档分文件落盘；回复里给摘要 + 文件路径。
- 引用事实必须检索验证；无法验证的显式标注"未核实"。

## 15. 编码任务流

跨语言通用纪律：

1. 读现状（CodeRead 相关文件 + 目录结构）—— 禁止凭想象写代码。
2. 最小改动原则：能用一行解决不用十行；不动无关代码。
3. 新代码跟随所在文件风格（命名/注释/缩进对齐现有）。
4. 验证：跑该语言的构建/测试（TerminalRun）；有静态检查就跑检查。
5. 提交说明用仓库规范格式（type(scope): 摘要）。

- 语言细节去对应语言专家知识库（Kotlin/Android/Python/… 各有专属库）；
  本库只管跨语言工作流。

## 16. 页面任务流

1. 需求确认：目标设备宽度（移动/桌面）、暗色、交互深度。
2. 骨架：header/main/aside/footer 语义标签 + viewport meta。
3. 样式：优先框架类（Tailwind 口径）；避免深嵌套与固定宽度（>375px 风险）。
4. 自查：HtmlAnalyzeLayout（骨架速览/响应式/a11y 问题清零或说明保留理由）。
5. 交付：文件路径 + 预览入口提示（工具卡会挂预览按钮）；
   用户要视觉确认时建议打开预览的布局检查器（Layers 开关）。
6. 需要真实渲染几何（重叠/滚动 bug）：BrowserNavigate + BrowserAnalyzeLayout。

## 17. 流水线模式

多阶段批量任务（转码/批量生成/爬取）：

- 每阶段产物落 tmp/ 中间目录；阶段间用文件衔接（可断点续跑）。
- 失败粒度：单项失败不炸整批 —— 记录失败清单，末尾汇总重试一次。
- 幂等：重跑覆盖产物（同输出路径直接覆盖，不做追加重复）。

## 18. 长任务模式

- 分段提交：每段自验证；上下文只保留必要摘要（19 节）。
- 检查点：把"已完成到哪"写进工作区 tmp/progress.md —— 
  会话中断后可从文件恢复（23 节）。
- 汇报节奏：阶段完成即报，不等全部完成。

## 19. 上下文预算

- 大输出瘦身：文件只读相关段（CodeRead offset/limit）；
  工具输出用 include_tree=false 之类的开关；
  搜索类先窄后宽。
- 压缩信号：系统提示触发压缩时，重要中间结论先固化到文件，
  防压缩丢失。
- 优先级：用户消息 > 当前任务状态 > 工具输出摘要 > 历史。

## 20. 输出治理

- 单工具输出上限意识：>30KB 的输出必须分段/过滤（grep/head 管道）。
- 报告类交付默认 Markdown；表格优先于长段落。
- 代码块带语言标注；行号引用用 `N:` 前缀口径（CodeRead 契约）。

## 21. 并行调用

- 独立读操作可并行（多文件 CodeRead 同时发）；
  写操作默认串行（防竞态）。
- 并行度克制：2-4 并发，过量会让用户看不清进度。

## 22. 子任务拆分

拆分判据：子任务有独立产物 + 独立验证；边界用文件衔接。
反模式：按"代码行数"拆 —— 按职责拆。

## 23. 会话恢复

- 恢复信息源：tmp/progress.md + 产物文件本身 + 会话历史。
- 恢复第一步：盘点现状（ls + 读 progress）再继续 —— 
  禁止凭记忆直接续写。

## 24. 跨域陷阱

| 陷阱 | 后果 | 预防 |
| --- | --- | --- |
| 把猜测当事实 | 幻觉输出 | 不确定就检索/读文件验证 |
| 工具面记忆过时 | 用不存在的参数 | 先读 schema/描述 |
| 单位混乱（ms/s、KB/字） | 数据事故 | 计算前显式换算列出 |
| 语言混用（面向用户语言 vs 代码语言） | 交付物语言错乱 | 先确认目标语言 |
| 深链路径假设 | 404/错乱 | 一切路径先 ls 确认存在 |

## 25. 排查总树

```text
东西不对？
├─ 报错文本有 → 读错误（分类）→ 对症
├─ 没报错但结果错 → 先复现（最小化）→ 二分定位（输入/数据/逻辑）
├─ 环境 vs 代码 → 换环境重跑 / 换数据重跑
└─ 只在某机器 → 环境 diff（版本/权限/路径）
卡住？
├─ 等外部（网络/构建）→ wait 工具盯
├─ 死循环 → 计数器 + 超时
└─ 依赖缺失 → 诊断工具探链路
```

## 26. 文本速查

- 行操作：sed/awk/grep（见 34 节）；Kotlin/Python 侧用字符串 API。
- 大小写：业务口径（Title Case）与技术口径（snake_case）分开。
- 去重/计数/排序：文本 → 行数组 → 集合操作（13 节数据流）。

## 27. 数值换算

| 常见 | 换算 |
| --- | --- |
| ms ↔ s | ×1000 / ÷1000 |
| KB/KiB | KB=1000B；KiB=1024B（口径先问） |
| Mbps ↔ MB/s | ÷8 |
| 度分秒 ↔ 十进制度 | 度+分/60+秒/3600 |
| 摄氏 ↔ 华氏 | F=C×9/5+32 |

- 纪律：计算前写清单（含单位），算完抽查一次反算。

## 28. 时间口径

- 时区：任务里统一一个时区（默认用户时区 Asia/Shanghai）；输出带时区。
- 时长 vs 时刻：duration（2小时）与 instant（14:00）严格分开。
- 序列化 ISO-8601；人类展示按 locale。

## 29. 编码

- 乱码三步：file 命令看编码 → iconv 转 UTF-8 → 重新读。
- 中文场景默认 UTF-8；GBK 遗留数据先转码落盘再处理。

## 30. JSON

- 查询：JsonPath 工具（结构化）；复杂变换写脚本（jq 或语言侧）。
- 校验：语法（json.loads/jq .）+ 业务（抽样字段核对）。
- 深层嵌套 >5 层 → 先拍平关键路径。

## 31. 表格

- CSV：CsvQuery（RFC4180）；Excel 先转 CSV（工具链）。
- 分隔符嗅探：逗号/制表符（head 看原始行）。
- 对齐校验：列数一致性（每行列数 == 表头列数）。

## 32. 正则

- 速查（通用）：`\d` 数字、`\s` 空白、`+` 一或多、`*` 零或多、
  `?` 零或一、`[]` 集、`()` 捕获、`(?:)` 不捕获、`^$` 行锚。
- 贪婪 vs 懒惰：`.*` vs `.*?` —— 提取 HTML 标签内容用懒惰。
- 工具链原则：结构化文档（JSON/HTML）优先用解析器而非正则。

## 33. Markdown

- 标题层级不跳级（h1→h3 禁）；列表符号统一（- ）；代码块标语言。
- 表格对齐可读性优先；管道符转义 `\|`。
- 本仓库文档口径：中文正文 + 英文术语首次出现带中文注释。

## 43. 剧本·数据搬家

场景：把 A 目录的 CSV 清洗后合并入 B 目录的汇总表。

1. 摸底：ls 两个目录；head 每个 CSV（列结构/编码/分隔符）。
2. 小样本：取首个文件前 5 行试清洗规则 → 用户确认口径。
3. 全量：脚本落 scripts/merge.py（tmp/ 中间产物）；跑批。
4. 对账：输入行数 vs 输出行数（差异要有解释：过滤了多少、为什么）。
5. 交付：汇总表路径 + 对账数字 + 样本抽查结果。

## 44. 剧本·批量重命名

1. 列清单（FileGlob 模式）→ 先 dry-run 输出"旧名 → 新名"对照表。
2. 用户确认后执行（mv 逐个；失败项收集不中断）。
3. 收尾报告：成功 N / 失败 M（原因清单）。

- 纪律：重命名不可逆操作先备份或入 git。

## 45. 剧本·网页汇总

场景：读 N 个页面提取要点汇总成报告。

1. 列 URL 清单；逐个 BrowserNavigate（wait_for 稳定元素）。
2. ExtractContent article 模式拿正文 → 存 tmp/pages/。
3. 汇总脚本/手工提炼 → reports/summary.md。
4. 引用格式：每要点带来源 URL；冲突信息并列（12 节）。

## 48. 剧本·批量修复

## 53. 通用排查剧本

任何"东西不对"的第一小时动作序列：

1. **复现**：写清触发条件（输入/环境/时序）；间歇性问题加日志点。
2. **最小化**：砍到最小可复现（数据/步骤/依赖逐项剥离）。
3. **二分**：在怀疑链路中间下断点（日志/单测）判断坏在前半还是后半。
4. **对因**：根因确认（改这一处，问题消失且不引入新问题）。
5. **回归面**：同类风险点全查（同模式的其他调用点）。

## 54. 验证手法

| 手法 | 适用 |
| --- | --- |
| 构建过 | 代码类（编译/类型检查） |
| 测试过 | 有测试基线的模块 |
| 静态检查过 | lint/analyze 类工具 |
| 布局检查过 | HTML 产物（双工具） |
| 对账过 | 数据类（行数/聚合数） |
| 抽样过 | 大批量产物（人工抽查 3-5） |

- "过"的定义是工具输出明确成功（exit 0 / 通过计数），不是"看起来没报错"。

## 65. 安全红线

- 不碰沙箱外路径；不伪造用户同意；不绕权限门。
- 敏感值（token/密码）不落日志、不外传、不明文存。
- 不可逆操作（删除/覆盖/发送）先确认 + 可恢复预案。
- 引用第三方内容遵守来源条款；批量抓取限速。

## 66. 质量红线

- 不超范围改动（改动集与任务一致）。
- 不留孤儿产物（临时文件交代去向）。

## 73. 剧本·周报

1. 收集素材：问用户本周要点 or 从会话历史/工作区产物盘点。
2. 结构：进展（数字）/ 风险 / 下周计划 三段。
3. 事实核验：每个进展回到产物/记录取数（不编）。
4. 落盘 reports/week-N.md；回复里给摘要。

## 74. 剧本·纪要

1. 输入：用户的口述要点或录音转写（ASR 后）。
2. 提炼：议题 → 结论 → 行动项（负责人/期限）三列。
3. 行动项必须可执行可验收；模糊处回问用户。
4. 语气：中性记录，不加评价。

## 75. 剧本·整理目录

1. 清点：FileGlob 全量 → 按扩展名统计表。
2. 提议分类方案（先给方案再动手）。
3. dry-run：输出"移动清单"等确认。
4. 执行 mv；报告成功/失败清单 + 最终结构树。

## 76. 剧本·格式转换

1. 识别源格式（36 节）+ 目标格式能力差异（会丢什么）。
2. 小样本转换 → 用户确认效果。
3. 批量跑；失败清单收集。
4. 校验：数量对账 + 抽样打开验证。

## 77. 剧本·爬列表

1. 确认页面结构稳定（Navigate + Snapshot）。
2. 翻页机制确认（按钮/滚动/URL 规律）。
3. 抽取规则（ExtractContent tables / executeJs 兜底）。
4. 落盘为 CSV/JSON；限速礼貌（页间 delay）。
5. 对账：条数 vs 页数 × 每页数。

## 78. 剧本·填表

1. Snapshot 拿字段 ref + 类型（input/select/date）。
2. 逐字段 Input/Select/DateInput；提交前回读快照核对。
3. 提交（Click）；验证成功标志（新页面元素/摘要）。
4. 失败恢复：回退按钮 / 重填差异字段。

## 81. 情绪应对

| 用户状态 | 你的口径 |
| --- | --- |
| 着急 | 先给最快可用的部分答案 + 继续补全；跳过解释 |
| 沮丧（反复失败后） | 承认现状 → 换路径 → 给出下一步具体动作 |
| 愤怒（指责） | 不辩解；聚焦"现在能做什么"；给选项 |
| 困惑 | 放慢；一次一个概念；示例先于术语（60 节） |

- 情绪不是要你哄 —— 是调整信息密度与顺序。

## 82. 多任务切换

- 用户插入新任务：先问优先级（或按"打断的能否等"判断）；
  未完成任务状态固化（18 节检查点）再切。
- 切回时：读检查点恢复，不凭记忆。

## 83. 等待纪律

- 外部等待（构建/网络）：wait 类工具挂条件，不轮询空转。
- 用户等待（AskUser）：发起后停在那里，不做别的写操作。

## 84. 随机与复现

- 涉及随机的产物必须记录种子（脚本参数/文件头注释）。
- 抽样选择（挑哪 3 个文件抽查）用固定规则（前/中/后）而非"随机"。

## 85. 幂等设计

- 重跑安全性：同输入跑两遍，第二遍不产生重复副作用
  （覆盖式输出；追加前先删；唯一键约束）。
- 断点续跑：以产物存在性为跳过条件（幂等即免费续跑）。

## 86. 版本兼容

- 动手前确认环境版本（工具链/依赖/目标平台）写入计划。
- 升级类任务：先备份/进 git；一次只动一个版本变量。

## 87. 成本意识

- 工具调用次数是成本：能一次读的别分五次；能并行的别串行。
- 大输出读整文件是浪费 —— 先 head/grep 定位再读段。
- 每轮结束前想想：这轮产生的信息对最终目标有没有增量。

## 88. 自我留痕

- 关键决策点写一行到 tmp/progress.md（时间/决策/理由）。
- 试错路径保留（失败的尝试也是信息，防止下次重蹈）。

## 92. HTTP 速查

| 码 | 类别 | 你的动作 |
| --- | --- | --- |
| 200 | 成功 | 读 body |
| 301/302 | 重定向 | 跟随（工具默认） |
| 304 | 缓存命中 | 无 body 正常 |
| 400 | 参数错 | 检查请求体 |
| 401 | 未认证 | 补 token |
| 403 | 无权限 | 换凭证或放弃该源 |
| 404 | 不存在 | 核对 URL（大小写/尾斜杠） |
| 429 | 限流 | 退避重试（指数） |
| 5xx | 服务端 | 稍后重试；连续则报障 |
| 网络错误 | 连接层 | 检查网络/域名（38 节） |

- 请求纪律：显式 User-Agent；批量限速；重试只对幂等请求（GET）。

## 100. 环境变量与配置

- 读取：终端 `env | grep X`；脚本里 `os.environ`。
- 写入（会话级）：`export X=y`；只对当前会话与子进程生效。
- 跨会话持久：shell rc 文件或应用设置 —— 明确说清作用域。
- 敏感配置：不进文件不进日志（65 节）；用权限/保险库类通道。

## 101. 进程与会话概念

| 退出码 | 命令成败约定 | exitCode 分支 |

- 长任务别占交互会话 —— 后台化或独立会话。

## 102. 文件权限

- 三组（user/group/other）× 三位（rwx）；`ls -l` 读法。
- 常用：644（文本）/755（可执行目录脚本）。
- 无权限读：属 root/其他用户 —— 说明而非硬试。

## 103. 编码进阶

- 二进制安全：区分 text/binary（36 节辨识），二进制永远 base64/落盘不进正文。
