## Coding 思考逻辑全面完善：AUTO 档四线统一 + 升级即时生效 + 子代理设置域收口

- **AUTO（Adaptive）档四条思考逻辑线统一**：此前发送前预检选档与深水区自动升档只在「深潜」线生效——切到标准 / 织造 / 信使线时 AUTO 静默退化成固定档（档位语义随线漂移）。现在预检与升级在四条线上一致运行，切线不再改变「自动」的含义
- **AUTO 预检档位当轮生效**：修复预检时序——此前深潜线上 AUTO 解析出的档位（如深水任务的 ULTRACODE）要等下一次发送才注入对应的编码思考指令，本轮一直在用兜底指令；现在解析在前、上下文重织在后，本轮即按解析档工作
- **深水区自动升档当轮跟进**：运行中检测到连环失败升级到 ULTRACODE 时，同步刷新编码思考指令（升级不只是调预算，方法论文本也从本轮后续迭代跟上），升档通知文案随系统语言本地化
- **子代理设置明确作用域（仅 Coding 模式）**：设置 → Agent → 子代理分区新增作用域提示行——Agent 聊天工位从不暴露编码工具（CodeTask 隔离），这里的开关与预算只在编程工位生效；副标题同步标注 Coding 域
- **标准线 AUTO 防御对齐**：标准线适配器对意外漏入的 AUTO 元档统一折叠到 DEEP 兜底（与织造 / 信使线同口径），并新增映射回归锁测试（宿主与库侧八档枚举同名对齐 + AUTO 折叠断言）
