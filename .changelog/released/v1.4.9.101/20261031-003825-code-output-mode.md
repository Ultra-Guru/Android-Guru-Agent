- Coding 工位输出展示双档：流式（Rikka 风格实时逐字渲染，默认，既有行为）与完整（生成中静默 + 加载进度卡，收束后一次性渲染完整时间轴）两档可切换
- 设置中心 → Coding 工位新增「输出方式」下拉（AgentSettings.codeOutputMode 持久化，随 AgentSettings JSON 落盘，重启恢复）
- 切换语义按规格书「只影响下一条消息或完成后的消息」：档位在每轮 run 开始时捕获（CodeViewModel.captureRunOutputMode），运行中改设置不打断当前轮展示
- 完整档加载进度卡（CompleteModeGeneratingCard）：三枚呼吸圆点 + 已用时跳秒 + 本轮工具计数 / 失败计数 + 骨架占位条——静默不等于黑箱
- 完整档收束即整段揭示：切片解除后时间轴一次性渲染，锚定收尾动画滚动一次到底；错误态走 ErrorBar 通道两档统一，切换不丢任何会话数据（切片是纯派生视图）
