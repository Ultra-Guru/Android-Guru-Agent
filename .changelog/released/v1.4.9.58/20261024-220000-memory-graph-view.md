# 新功能：记忆图谱视图 —— 六类记忆节点 × 六类关系边的交互式可视化

- 记忆页新增「图谱 / 列表」双形态切换（顶栏树状图标）：把情景、宏技能、聊天事实、知识实体、UI 节点、应用簇六类记忆画成一张可漫游的关系网（apex-kit-memory:memory-graph-ui 库首发）
- 力导向布局自动成形：同应用 / 同类别记忆自然聚团，连线长度表达语义距离；支持捏合缩放、单指平移、拖拽任意记忆节点重新安家（松手邻域记忆轻轻让位）
- 点按任意节点 → 底部弹出该记忆的完整内幕：情景（目标 / 动作数 / 观察到的 UI 元素 / 蒸馏产出的宏）；宏技能（动作序列时间线 / 能量条 / 成功率 / 晶化勋章）；聊天事实（类别 / 重要性 / 来源）；知识实体（观察记录 / 三元组关系）；应用簇（包内成员统计与样本）
- 选中节点后邻接记忆高亮、其余淡出 —— 一眼看清这段记忆的关系网；详情内可点「溯源情景 / 派生宏 / 相邻实体」芯片在图上直接漫游跳转
- 六类过滤 chips + 搜索（命中橙环高亮）+ 图例说明；晶化宏带金色勋章环、情景节点带成功 / 失败状态点、跨版本别名桥虚线可见
