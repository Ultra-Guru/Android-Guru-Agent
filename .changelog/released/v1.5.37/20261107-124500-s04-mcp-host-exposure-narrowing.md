- 安全加固：逆向 MCP Host 默认只监听本机回环地址 —— 局域网设备默认无法连接；PC 控制需在设置中显式开启「允许局域网访问」，开启后界面常驻明文传输风险警示
- 安全修复：GET / DELETE 等全部 HTTP 方法统一先过令牌鉴权 —— 此前未带令牌的 DELETE 可直接删除已连接会话
- 暴露面收窄：删除/卸载等高危工具永不再暴露给外部 AI；写文件、git 提交等副作用工具默认不暴露（需独立开关显式开启），只读工具不受影响
- 启用 MCP Host 前新增确认弹窗（列明端口、鉴权与暴露口径）；对外上报的版本号与 App 版本对齐
