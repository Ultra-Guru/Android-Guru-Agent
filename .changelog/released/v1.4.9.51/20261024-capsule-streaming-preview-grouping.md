# 胶囊流水线 v3：参数流式可视化 + 同族聚合胶囊

- **写/编辑实时可视**：LLM 流式生成 tool_calls 参数期间，新增
  `ToolCallArgsDelta` 事件逐帧上抛（引擎累积与上抛同源，全量参数与旧管线
  零差异）；Coding 胶囊时间轴对半截 JSON 做**增量键锚定提取**（结构性
  锚定防值内同名文本误命中、转义感知解码、尾部不完整 `\u` 存进度等下片、
  超长截头留 24K 尾窗），写文件绿色流入 + 尾部光标块、编辑文件红删
  （`−` 前缀）在前绿增（`+` 前缀）在后——正在写入的代码过程实时可见。
- **过程自动展开/完成收回**：参数生成期即建「等待态」胶囊（工具意图先于
  执行可见），实时代码窗随分片展开；Start 到达升级为运行态（预览保留、
  计数不重复），Complete/中止自动收回折叠为单行胶囊；点击胶囊详情层同款
  实时预览（400 行大视口）。名字晚到的 provider 由分片缓冲兜底回放。
- **同族聚合胶囊**：同族连续胶囊 ≥2 收成一颗——折叠态始终展示**最新
  调用**（名称/命令/状态/耗时与单颗同款）+ ×N 计数徽标；展开态平铺全部
  历史胶囊、每颗可点击进详情、头行可再收起；几十条终端命令只占一行。
- **聚合流水式生命周期**：分组内出现活跃胶囊自动展开（否则折叠态会遮住
  实时代码窗）、全部收束且未手动干预自动收回；手动展开/收起永远优先，
  新流式周期重置手动态（与终端面板/思考卡同款语义）；预览长度计入贴尾
  锚定素材——代码流入时时间轴跟随。
- 兼容口径：CodeEdit（old_string/new_string）与 Agent 屏 FileEdit
  （edits[].search/replace）两组键名都监听；MCP/未知族不建等待态胶囊，
  Start 按原路径兜底——旧管线行为零回退。20 例新测试锁定归约语义
  （升级幂等/迟到分片忽略/中止收口/缓冲回放/终端三信号）。
