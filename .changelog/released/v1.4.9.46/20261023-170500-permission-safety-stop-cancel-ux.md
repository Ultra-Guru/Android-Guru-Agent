# 权限安全线修复 + 停止真取消 + 历史会话数据完整性 + 界面文案去 AI 感

- 全自动（BYPASS）权限档补上两条安全线：用户手写的拒绝/询问规则重新生效（旧实现静默吞掉，与文案承诺相悖）；付费等敏感动作（如发短信）保持逐次确认——显式放行规则命中时视为用户已表态直接放行。配套修正权限模式说明文案（中英双语）
- 修复付费工具逐次确认已整体失效的问题：会话级放行黑名单仍存旧版 snake_case 工具 id（sms_send），PascalCase 化后的 SmsSend 从不命中——现两态并存并提升为权限门与风险门共用的单一事实源；权限门弹窗对付费工具不再提供「本会话允许」选项（与风险门同口径）
- 「停止/发新消息」真取消：取消等待超时后强制取消引擎镜像收集协程（关闭在途 LLM HTTP 流、终止工具执行、释放互斥位），并等待互斥位释放——旧实现超时返回后在途工具照跑、token 继续烧，紧随其后的新消息撞互斥锁被丢弃并弹英文技术错误；发送路径增加互斥位有界重试兜底
- 流式输出中段丢字防御：UI 快照比引擎全文短时（事件积压超水位线丢过过程 chunk）完成消息回退引擎全文——「丢过程不丢结果」与「看到什么落什么」两套承诺不再互相顶牛
- 聊天历史完整性三修：置顶会话不再被滚动归档静默挤出（置顶不参与淘汰）；删除「正在聊的」会话后屏幕与引擎历史同步清空（旧实现下一条消息把已删对话以新会话复活成幽灵）；恢复会话读不到消息时给出可见提示（旧实现静默无反应）
- 恢复会话时失败的工具卡不再伪装成成功（红卡不再变绿卡）；Agent 屏对齐 Coding 屏：工具开跑即收口思考气泡与计时（思考时长不再混入工具耗时），出错/中止瞬间已流出的思考内容保留为终态消息而非无声消失，salvage 顺序对齐真实时序（思考在前回复在后）
- 技能工具 PascalCase id（SkillInstall 等）在「接受编辑」档下恢复免确认豁免（旧前缀表只认 snake_case）
- 界面文案去 AI 感（中英双语同步）：移除聊天/编码/目标/终端/市场/诊断等界面文案中的 emoji 前缀（思考/中止/压缩/超时/拦截等约 60 处）；首屏人格化营销腔改为克制的产品文案（「全能 AI 助手」→「Android 上的 Agent 工作台」、「配置你的 AI 大脑」→「接入模型」等）；「一键×6」「智能安装」等模板词改为自然表述；设置页 Agent 行为区整节英文残留资源化为中文（重试与循环检测/自动恢复/自我评审/后台常驻等 21 项）；计划卡英文硬编码标题资源化；输入法密钥引导卡星光图标改为钥匙图标
