## Agent 对话流视觉重做：紧凑气泡 + 卡片外操作行 + 全量 M3 化

- 对话气泡头部大幅瘦身：「YOU / AGENT」角色标压成单行小字（去头像井、去 48px 溢出菜单行），流式回复与思考胶囊不再有大块留白
- 消息操作改为气泡卡片外下方的图标行：用户气泡配「复制 + 编辑」两枚图标，Agent 回复结尾只有「复制」一枚 —— 「整理到记忆」人头图标随记忆系统重构全面退役
- 新增「编辑消息」：点用户气泡下编辑图标可在对话框中修改原文，确认「重新发送」后以修改后的内容重新回答
- 消息流全量去液态玻璃：Agent 回复、流式输出、思考胶囊、工具卡、任务状态卡、计划/规格卡统一改为 Material 3 实色容器（状态色收敛为卡片描边），滚动与流式更省性能
- 气泡三点溢出菜单退役：原「复制全文 / 重生成 / 删除」等入口由卡片外图标行取代，界面更干净
