# 胶囊流水线 v4：全面可视化增强

- **运行统计收尾卡**：Complete 收尾从纯文本「完成 · N 轮 · N 次工具 ·
  Ns」状态行升级为结构化统计卡——头行（完成图标 + 总耗时）+ FlowRow
  统计 chips（迭代轮数 / 工具调用 / 触碰文件 / 失败数），失败 >0 全卡
  错误色转述；失败数为**本轮口径**（会话累计差值，跨 run 不串台）；
  检查点扁平化存取（"runstats" 类型，旧档默认 0 双向兼容）。
- **聚合胶囊调用历史状态条**：折叠态聚合胶囊在主行下方新增历史条——
  每次调用一枚色块 tick（终态按成对语义色着色：绿成 / 红败 / 琥珀中断；
  运行中族色**呼吸脉冲**），几十条命令的成败分布不展开即可扫读；
  tick 上限 12 + 超出「+还有 N 个」文本（复用文件 chips 省略键）。
- **实时进度迷你条**：单颗胶囊在 RUNNING 且有进度时展示 2dp 细条——
  编辑类按 hunksApplied/Total、其余按 ToolProgress percent（0..1 与
  0..100 两套量纲都兼容），推进感不再只靠数字徽标。
- **流式光标呼吸动画**：实时代码窗的尾部光标块从静态「▍」升级为
  0.15↔1 透明度往返脉冲（750ms，AnnotatedString 单 span 着色）——
  写入进行中的「活」感；终态收束后随窗口销毁停。
- **验证轮次卡增删徽标**：轮次头行新增 +N −M 行级改动量徽标（轮内编辑
  胶囊 diff 原文现场解析求和，绿增色与全局口径一致）；恢复回放的轮次
  calls 为空则不显（红绿态保留）。
- 测试：统计卡字段 / 失败数跨 run 基线 / 检查点往返 3 例新测试，2 处
  旧「完成状态行」断言同步迁移到结构化条目。
