- 任务剧本（Playbook）核心引擎落地：剧本 = 主提示词 + 分幕子提示词 + 触发词表，模板从「静态文本」升级为 agent 可自动选择使用的分幕战术手册
- 发送前任务识别器（纯函数双门：绝对分 ≥4 且领先次优 ≥2 才建议挂载），可解释理由随建议条展示，不做 LLM 调用零成本
- 分幕推进判定器：本幕切片实质产出 + 下一幕章节头才放行（诚实门：空洞产出绝不静默进幕）
- 幕侦察绑定：复用既有确定性分析器（代码审查启发式/用例等价类/Bug 分诊/重构规划），幕激活时产出确定性发现附录
- 指令构建器预算收缩（主提示词与幕头永不截断，附录先收缩）；SEQUENCED 渐进注入只带当前幕，COMPOSED 单轮合成全幕
- 首发内置 5 套剧本：代码审查 / 测试用例 / Bug 定位修复 / 重构方案 / Git 提交信息
- 剧本注册表与模板库同纪律：playbooks.json 原子写、内置不可改 + 篡改自愈、导入永不伪造内置、重播种还原
