## 记忆页全面升级：手动写入口 + 知识图谱分区 + 三轨统一搜索

- 记忆页新增「添加记忆」入口：「记一条事实」手动保存长期事实（画像/近况/里程碑 + 重要度），「教一次经验」把目标/结果/成败/教训（每行一条）整包沉淀 —— 与 agent 的记忆写入工具同落点，你教的门道 agent 之后会一并召回
- 列表视图新增「知识图谱」分区：实体卡呈现类型徽章、观察记录与关联关系（「—关系→ 对端」方向归一），按关联数排序（最中心的知识排最前）；点击「在图谱中查看」直达图谱画布并自动定位选中该实体节点
- 搜索升级为三轨统一命中：事实、知识实体、场景节点分组展示，各带类型徽章；事实与实体命中可一键跳转图谱定位对应节点
- 概览统计从三项扩为六项：会话、节点、宏技能 + 事实、实体、关联关系
- 写入/删除后图谱画布经库侧修订号信号自动软刷新（保位/保选中，探索现场不丢），列表与图谱数据保持一致
- 修复英文环境下的中英混杂：聊天记忆的类别标题与来源标签（启发式/蒸馏/手动/迁移）改为资源驱动双语
