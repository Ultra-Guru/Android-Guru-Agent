- FUSION 聚合包新增「组合我的聚合包」：从已安装的技能 / MCP 服务器 / 功能插件中自由勾选成员，1 个是聚合、多个混搭也是聚合——命名并保存后与内置体系包同权（王冠菜单选用、一键激活、强制使用协议）；自建包支持编辑成员、删除、导出 JSON 分享
- 聚合包新增「安装成员」：聚合可引用官方仓库里尚未安装的技能与 MCP（skillPicks/mcpPicks），点「安装成员」一键装齐（不激活）；组合器可直接从官方仓库目录勾选成员建套装——换机重装一套聚合即可拉齐全部依赖
- 聚合包（FusionBundle）manifest 新增 plugins[] 段：功能插件可随包一键聚合激活（斜杠指令 / 工具宏经既有插件管线落位），单组件失败进跳过清单不弃包
- 王冠菜单新增「导入 Claude 插件包（.zip）」：Claude 生态的 skills（SKILL.md）/ commands / agents 三段自动映射为本机聚合包——技能名 kebab-case 自动归一 PascalCase、commands 变斜杠指令、agents 变体系人设，导入即用
- 插件支持带 UI 页面（双轨）：功能性插件可在 plugin.json 声明 HTML 页面（市场插件行「打开页面」直接查看，文件不越出插件目录）；APK 插件可声明原生 UI 入口（同签名校验通过后跳转插件自己的页面）
