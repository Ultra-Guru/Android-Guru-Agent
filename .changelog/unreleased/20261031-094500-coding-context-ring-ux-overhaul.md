- Coding 顶栏图标语义重构：长任务 = 对话气泡图标（点击展示执行过的任务，卡片操作：复制任务 / 重跑 / 检查点续跑 / 对比上次 / 导出分享 / 删除），对话历史 = 时钟图标（直觉指向「历史」），两者互换不再歧义
- 新对话图标由裸「＋」换为对话气泡加号（AddComment）——「发起新对话」一眼可读
- 会话上下文眼睛图标退役，改为「上下文用量圆环」（新对话图标右侧）：圆环白弧按上下文占用百分比实时填充，用量涨多少弧就走多少；点击展开详情卡——上下文占用（used/max/百分比）、会话累计输入输出 tokens、缓存命中率（OpenAI 兼容端点 prompt_tokens_details.cached_tokens 真实统计，端点不返回时显式显示「暂无数据」而非假 0%）
- 圆环分母接通真实模型窗口：默认模型 Profile 的 contextWindow（effectiveContextWindow），切模型即正确反映 8k/200k 差异，不再恒按硬编码 128k 满打满算
- 长任务中心的「任务模板」「档位效能」两页签随功能整体删除：LongTaskTemplates / 档位统计追踪器 / 模板记录豁免 / 复制任务的档位覆盖全链路移除（含 DI、持久化语义与字符串）
- 设置中心归类合并（27 叶 / 6 分类 → 24 叶 / 5 分类）：上下文压缩并入「上下文」、限速友好并入「网络」、高级选项并入「提示词」、对话显示并入「外观」、本地搜索并入「工作台」——同类设置归为一页，不再一个开关一页
- 假设置清理与真接线：删除无消费方的视觉三件套（Enable Vision/截图质量/截图上限）与 Coding 假开关（工具面/读守卫/自动项目规则）；「任务完成通知」接通真实通道（后台跑完发系统通知、前台静音、中止不打扰）；token 用量仪表盘接通逐轮落账（UsageLedger 从此有真数据）
