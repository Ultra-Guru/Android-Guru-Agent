- 新增 Coding 工位「子 Agent / 终端命令」轻量仪表盘：输入栏工具栏行右端小按钮（运行中子 Agent + 运行中命令角标）弹出只读浮层，双 Tab 集中展示当前对话的子代理列表与终端命令执行状态
- 每个对话独立：会话号按新会话 / 恢复历史 / 切工作区换号弃桶，迟到旧会话事件直接丢弃不串台；仪表盘纯内存态不落盘，恢复历史对话后为空（严格「关闭即清」）
- 只读观察层零侵入：SubAgentRunner 新增可选观察者（默认 NoOp 零开销），主代理命令在 VM 事件收集处一行旁路；子代理中间过程不进主对话历史、不改隔离上下文语义
- 状态诚实口径：命令成败以 exitCode / success 为准（0 成功，127/126/-1 失败），子代理终态以收官原因为准（完成/超时/取消/失败）；中止时在飞行就地收口为「已中断/已取消」，不挂永久「运行中」
